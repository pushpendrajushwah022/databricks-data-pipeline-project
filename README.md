# Databricks Data Pipeline Project

## 📌 Project Overview

This project demonstrates an end-to-end data pipeline built using Databricks.

The pipeline performs data validation, transformation, filtering, and joins using Python, PySpark, SQL, and Delta Lake.

## 🛠️ Technologies Used

- Databricks
- Python
- PySpark
- SQL
- Delta Lake
- Git & GitHub

## 🔄 Pipeline Workflow

1. Load source data
2. Validate data quality
3. Apply validation rules
4. Transform the data
5. Join people data with department data
6. Generate the final transformed table
7. Run the pipeline successfully in Databricks

## 📊 Data Quality

The pipeline includes validation rules for:

- Age
- Salary
- Required fields
- Department information

## 📈 Project Result

The Databricks pipeline was successfully executed and the transformed data was generated.
